2. Données personnelles collectées

Nous collectons uniquement les données nécessaires au fonctionnement de NovaMeet V2 : email, date de naissance (validation majorité), genre, préférences de recherche, ville approximative si autorisée, langues parlées. Aucune donnée sensible non nécessaire n'est collectée.

3. Comptes et profils

Informations de profil : pseudo, bio, centres d'intérêt, photos que vous choisissez de rendre visibles. Vous contrôlez ce qui est public dans les paramètres de l'app.

4. Photos et vidéos

Photos de profil stockées via le service de stockage de notre backend. Elles sont utilisées uniquement pour affichage dans l'app et modération anti-fraude. Pas de reconnaissance faciale automatisée à des fins publicitaires.

5. Messages privés

Messages entre utilisateurs chiffrés en transit (TLS). Stockés pour permettre l'historique. Non lus par l'équipe sauf signalement explicite de votre part dans le cadre d'une enquête pour abus.

6. Notifications

Notifications push (matchs, messages) via Apple Push Notification Service et, si Android, Firebase Cloud Messaging. Vous pouvez les désactiver dans les réglages système.

7. Données techniques

Adresse IP (sécurité), type d'appareil, version OS, logs de connexion, identifiants anonymes. Pas de tracking publicitaire tiers sans consentement.

8. Données éventuellement collectées par Supabase

NovaMeet V2 utilise Supabase comme backend (service européen si configuré en région EU). Données concernées : authentification (email, hash mot de passe), base de données Postgres (profils, messages), Storage (photos), logs techniques. Supabase agit en sous-traitant. Région d'hébergement : à vérifier dans dashboard Supabase V2 (recommandé: eu-central-1). Voir politique Supabase pour détails.

9. Prestataires techniques

Supabase (backend), Apple (achats in-app), GitHub Pages (hébergement de ce site), Gmail (support - Google). Aucune revente de données.

10. Durées de conservation

Compte actif : durée d'utilisation + 12 mois d'inactivité avant anonymisation. Messages : conservés tant que le compte existe. Logs sécurité : 13 mois. Données comptables si achats : obligations légales françaises (5-10 ans). Suppression définitive sur demande : voir page suppression.

11. Droits RGPD

Accès, rectification, effacement, opposition, portabilité, limitation. Exercice: écrivez à novameet.privacy@gmail.com depuis l'email du compte. Réponse sous 30 jours. Réclamation possible auprès de la CNIL.

12. Sécurité

TLS, hashage mots de passe, Row Level Security Supabase, modération manuelle, signalement in-app. Aucune méthode de sécurité n'est infaillible, signalez tout incident à novameet.privacy@gmail.com

13. Transferts hors UE

Si certains prestataires sont hors UE (ex: Gmail/Google), transferts encadrés par clauses contractuelles types. Hébergement principal visé en UE. Contactez novameet.privacy@gmail.com pour détails.

14. Suppression des données

Procédure complète sur /suppression-compte.html ou par email à novameet.privacy@gmail.com. Suppression du profil, photos, messages, préférences sous 30 jours maximum, sauf obligations légales (fraude, comptabilité). Confirmation par email.
